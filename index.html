English

A TypeScript SDK for local text/image inference, document questions and structured website reports using pinned Qwen3.5 ONNX models. Requires Node.js 22.13+ or a supported WebGPU browser. Explicit device selection; no unsupported CPU/WASM browser fallback.

Usage and API guide Quality and measured limitations Security and privacy

Build the current source

git clone https://github.com/JS-PACKAGE/Neko.js.git
cd Neko.js
npm ci
npm run build
npm pack

This project is not published to npm. Install the tarball printed by npm pack with npm install /absolute/path/to/package.tgz. Review native install-script approvals and model licenses in the guide. Initial setup downloads pinned, integrity-checked assets; remote URL inputs cause explicit network requests.

Model output is untrusted and may be wrong. Contract tests and configured providers do not prove inference quality or hardware execution. This static page performs no inference, collects no input and loads no third-party scripts.

取得套件

本專案不發佈至 npm。請依上方指令 clone 並建置目前原始碼，以 npm pack 產生 tarball，再使用 npm install /absolute/path/to/package.tgz 安裝印出的檔案。原生安裝腳本核准與模型授權請參閱使用說明。首次設定會下載並驗證固定模型檔案；遠端網址輸入會發出明確的網路請求。

模型輸出是不可信資料，可能不正確。契約測試或 provider 設定不代表推理品質及硬體執行證據。本靜態頁面不執行推理、不收集輸入，也不載入第三方腳本。
